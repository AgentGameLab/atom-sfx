# 录制说明

> 让工具读得懂你的录音需要满足的条件。不是录音技巧，是数据要求。

## 怎么录

按拟音本来的方式做就行：

1. 拿起一个东西
2. **对麦说**：这是什么、准备怎么弄、大概什么声音、要录几组
3. 录
4. **换档的时候按 `M` 打一个 marker**
5. 换个手法或换个东西，回到第 2 步

一条长 wav 录到底，不用分文件。录废了直接重敲，废的那下自己剪掉。

## 口报里说清三样

不用背模板，正常说话就行，句子里带上这三样就能解析成属性：

| 说什么 | 例子 | 变成 |
|---|---|---|
| **是什么** | "敲击一块带垫子的木桌面" | `source` |
| **怎么弄的** | "用手指尖、指甲那块儿" | `technique` |
| **分几组、每组什么** | "轻三下、中三下、重三下，第一组敲中间" | `axis` + 分组 |

顺带说说音色（"木质回响、比较沉闷"）也有用——那些形容词能对到物理量上（沉闷 = attack 慢 + 衰减长，都是能算出来的），攒多了就是一张你自己的词表。

### 不方便口报的时候

腾不出嘴（双手都在忙、动作连贯不想打断）就别报，**光靠 marker 分组也能切**——没有口报时工具会建一个虚拟组，marker 直接当档位边界。属性写进 map JSON 就行，反正口报最后也是人读一遍写下来的。

但有一类要额外加一个参数：**软冲击**（打身体、闷响、隔着东西打）的 attack 是 30-80ms，**跟说话完全重叠**，工具分不出来，会把其中几下当成口报吃掉。

```
打肚子那卷 18 下：默认只认出 14 下，4 下被判成口报
        —— 那 4 下 attack 57/407/176/77ms，说话是 30-80ms
```

给它一张空的语音表，口报检测就整个关掉，剩下的全算素材：

```bash
echo '{"spans":[]}' > nospeech.json
atom-split --input take.wav --speech nospeech.json --map x.json --out atoms/
```

判断标准很简单：**这卷录音有没有说话**。有就正常跑（或者 ASR 转一份真的 speech 表），没有就传空表。

## marker：只在换档时按

不用每下都打。**换力度档、换手法、换位置的时候按一次 `M`** 就够。

为什么需要它——实测数据：

某次录音主观分了轻/中/重三档，切出来的峰值是

```
-20.1  -23.0  -20.8  -20.4  -20.2  -21.2  |  -14.0  -15.3  -13.9
```

算法能准确切出这 9 下，但**前 6 下的轻和中在数据上完全分不开**。marker 把这个边界定死，不用猜。

**存成 wav**，marker 会写进文件的 `cue` chunk 跟着走。存成 `.sesx` session 的话 marker 留在工程里，工具读不到。

marker 不用命名（默认的"标记 01"就行），命名了工具也会读。

## 三条数据要求

**1. 开头留 3-5 秒静默。** 什么都别做，就录环境。工具拿它算自适应噪声地板。

> 有兜底但不如直接给：工具会同时取「开头静默」和「全局 10 分位」里更小的那个。真实录音里段间静音总是占多数，所以开头没留也能算出来——只是没那么准。

**2. 全程别改增益。** 力度轴的全部意义就是真实能量差（轻放和重敲不只是音量不同，包络形状也不同）。中途调了增益，轴就废了。

**3. 留足 headroom，最重那档也别顶。** 目标峰值 **−6 ~ −10dBFS**。

> 这条最容易大意，实测教训：某次录音 `max_volume` 到了 0.0dB，中心位置那组轻/中/重的峰值全挤在 −1.4dB 附近——**力度轴在峰值维度上被压平了**。同一批录音里靠边那组因为本身弱，轴保留得很完整（−12.2 → −6.4 → −0.3，跨度 12dB）。
>
> 归一在后期做是无损的，录小了没关系，顶掉了回不来。如果发现某个数值（比如 −1.4dB）在很多个 take 上反复精确出现，那是录音链里有软限幅顶在那儿，检查一下输入增益和录音软件的保护设置。

**一批一次录完，别隔天补。** 环境和材料状态会变，隔天补的坐标点会成为轴上的异常值。

## 自己先剪一遍的话，两个别剪

剪辑的本能是剪紧、把"没用的"静音删掉，这两处正好是工具要用的：

- **开头那 3-5 秒静默** —— 噪声地板的来源
- **段与段之间 ≥200ms 静音** —— 分段依据（阈值 150ms），剪太紧两下会被当成一段

其余随你剪，工具只认音频，不管谁切的。

## 录完

```bash
atom-split --input take.wav --dry-run
```

先看 `--dry-run` 报告：口报分成几段、每段几个 take、每档几下、每一下的 attack / 时长 / 峰值。确认无误再配属性正式切。

组数对不上时工具**拒绝写文件**，不会静默切错。
